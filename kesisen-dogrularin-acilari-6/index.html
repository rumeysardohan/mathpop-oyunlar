Kesişen Doğruların Oluşturduğu Açılar · Çalışma Kağıdı 1
1. soru → x = 50°, y = 130°, z = 50°y, 130°'nin ters açısıdır: y = 130°. x ve z, 130°'nin komşusudur: 180° − 130° = 50°.
2. soru → a) 72° b) 108°Ters açılar eşittir, yani 72°. Komşu açı: 180° − 72° = 108°.
3. soru → a − b = 104°a, 38°'nin komşusu: 180° − 38° = 142°. b, 38°'nin ters açısı: 38°. 142° − 38° = 104°.
4. soru → 110°Toplam 180°. 180° − 40° = 140°, ikiye böl: küçük açı 70°, büyük açı 70° + 40° = 110°.
5. soru → x = 70°60°'nin ters açısı, 50° ile x'in arasındadır. Yatay doğrunun üstünde: 50° + 60° + x = 180°, x = 70°.
6. soru → 115°Açı: 90° − 25° = 65°. Komşu açısı: 180° − 65° = 115°.
7. soru → x = 40°130°'nin komşusu 180° − 130° = 50°'dir; bu açı d₁ ile d₂ arasında, x'in hemen yanındadır. [OK dik olduğu için 50° + x = 90°, x = 40°.
8. soru → 260° Yan yana iki köşenin toplamı 180°. Küçük açıya 1 parça dersek büyük açı 2 parça + 30°. 3 parça + 30° = 180°, 3 parça = 150°, 1 parça = 50°. Küçük açı 50°, büyük açı 2 × 50° + 30° = 130°. Geniş açılı iki köşe ters açılardır: 130° + 130° = 260°.
